Verify a Counterroll record

Check that a decision record was signed by the key you trust and has not been changed since. Free.

This tool checks your files in your browser. It does not upload your files or records.

What verification means

Someone can check that a record came from Counterroll and wasn't edited, without having to ask us.

In the example below, an agent asks to spend 9.00 against a 5.00 cap. Counterroll records "DENY: over the cap" and signs it. Check it with the trusted public key and the original passes. Change "DENY" to "APPROVE" and the edited copy fails.

Think of it like a tamper-evident seal on a receipt. It proves what Counterroll recorded, not that the decision was correct or that money moved.

Check your own record

What a pass proves

  • The record was signed by whoever holds the private half of the key you used.
  • None of the signed fields changed since: decision, reasons, amount, payee, agent, policy, time, and the link to the previous record.
  • For a list of records: they link up from record 1 as presented.

What it does not prove

  • That the key is Counterroll's. That depends on how you got it. A record re-signed with a made-up key passes against that made-up key.
  • That the decision was correct, or that any money moved or did not move.
  • That you have every record. A list with its newest records removed still links up.
  • Anything about requests that never got a signed record. Some refusals (an unknown agent, a malformed or repeated request) leave only an unsigned event or nothing.

Run it on the command line

The same check, open source under the MIT licence, with no dependencies. With Node 18 or later:

git clone https://github.com/Counterroll/verify
cd verify
node bin/counterroll-verify.mjs examples/refusal-original.json --key <key>

The record format is published in FORMAT.md. It is Counterroll's own format, not an industry standard.
